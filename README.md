- **Highlights:**

Managing and optimizing enterprise digital banking systems to ensure high performance, reliability, and secure integrations.

- **Technologies:** `WSO2` `Red Hat` `JBoss ERP` `Temenos Transact (T24)`
- **Highlights:**

- **Technologies:** `React` `Node.js` `MongoDB`
- **Highlights:**
  - Real-time updates
  - Responsive user interface
  - Secure authentication system
- **Live Demo:** [equib-ms.vercel.app](https://equib-ms.vercel.app/)
